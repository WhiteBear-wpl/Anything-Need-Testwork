# AI 用例管理平台 接口文档

- Base URL：`http://127.0.0.1:8000/api`
- 数据格式：请求与响应均为 JSON（文件上传使用 `multipart/form-data`，导出接口返回文件流）
- 错误格式：`{"detail": "错误描述"}`；参数校验失败返回 422（FastAPI 标准结构）
- 在线调试：服务启动后访问 `/docs`（Swagger UI）

## 通用状态码

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 201 | 创建成功 |
| 204 | 删除成功（无响应体） |
| 400 | 业务校验失败（如未确认功能点就生成、文件类型不支持） |
| 404 | 资源不存在 |
| 422 | 请求参数校验失败 |

## 2. 项目 Projects

### GET /projects/overview
首页总览：项目数、用例数、生成次数、各项目统计、最近活跃项目。

### GET /projects
项目列表（按更新时间倒序，不含评测隐藏项目）。

### POST /projects — 201

```json
// 请求
{ "name": "电商系统 v2.0", "description": "订单与支付模块" }
// 响应
{ "id": 1, "name": "电商系统 v2.0", "description": "...", "created_at": "...", "updated_at": "..." }
```

约束：`name` 必填，1~200 字符。

### GET /projects/{project_id}
### PATCH /projects/{project_id}
请求体字段均可选：`name`、`description`。

### DELETE /projects/{project_id} — 204
级联删除需求文档、生成任务、用例与知识库（含 Chroma 向量）。

## 3. 需求文档 Requirements

前缀：`/projects/{project_id}/requirements`

### GET ``
文档列表（含功能点 items）。

### POST `` — 201
文本导入：

```json
{ "title": "登录模块 PRD", "content": "用户登录功能：支持手机号+密码登录..." }
```

响应字段：`id`、`title`、`source_type`（text/docx/markdown/featurelist）、`status`（uploaded/structured/confirmed）、`test_scope`、`items[]`。

### POST `/upload` — 201
文件上传（multipart）：`file`（.docx/.md/.markdown，≤10MB）、`title`（可选，默认取文件名）。
非法类型返回 400；`.doc` 返回 400 并提示转存 `.docx`。

### POST `/{document_id}/structure`
调用 LLM 将原文解析为功能点列表，文档状态变为 `structured`。

### POST `/{document_id}/confirm`

```json
{ "item_ids": [1, 2, 3] }   // null 或省略表示全量确认
```

勾选项 `confirmed=true`，全部确认后文档状态变 `confirmed`。

### PATCH `/{document_id}/scope`

```json
{ "test_scope": "{\"in_scope\":[],\"out_scope\":[\"第三方登录\"],\"risks\":[\"锁定阈值待确认\"]}" }
```

### POST `/{document_id}/scope/generate`
AI 生成测试范围建议，写入 `test_scope` 并返回文档。

### 功能点管理

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/{document_id}/items` | 新增功能点（`feature` 必填 1~200 字符），201 |
| PATCH | `/{document_id}/items/{item_id}` | 编辑功能点；已确认文档会回退 `structured` |
| DELETE | `/{document_id}/items/{item_id}` | 删除功能点，204 |

### 功能清单导入导出

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/{document_id}/featurelist/export?format=xlsx\|md` | 导出功能清单文件流 |
| POST | `/featurelist/import` | 上传 .xlsx/.md 清单，创建 `structured` 文档，201 |

## 4. 用例生成 Generations

前缀：`/projects/{project_id}/generations`

### POST `` — 201

```json
{
  "document_id": 1,
  "strategy": "full",              // full | quick
  "specialist_skills": ["security"], // 可选：security / api_test
  "use_knowledge": true            // 开启 RAG 检索
}
```

前置校验：文档必须为 `confirmed`，否则 400。任务异步执行，通过轮询获取进度。

### GET `/{task_id}`
任务详情：`status`（pending/running/completed/failed）、`progress`（0~100）、`stage`（阶段文案）、`tokens_used`、`knowledge_refs`（RAG 溯源 JSON）、`drafts[]`（候选用例）、`quality_report`（质检报告）、`review_stats`（评审统计）。

草稿字段：`title`、`priority`、`case_type`（functional/boundary/exception）、`is_smoke`、`precondition`、`steps`（JSON 数组字符串）、`expected_result`、`quality_status`、`review_status`（pending/adopted/rejected/edited）、`reject_reason`、`was_edited`、`judge_score`（1~5）、`judge_issues`。

### GET ``
任务列表（含草稿）。

### GET `/summary`
生成记录摘要：`draft_count`、`smoke_count`、`coverage_rate`、`review_stats`、`document_title`，不含草稿明细。

### POST `/{task_id}/review`

```json
{ "draft_ids": [1, 2], "action": "adopt" }                          // 采纳，返回入库用例列表
{ "draft_ids": [3], "action": "reject", "reject_reason": "重复场景" } // 驳回，返回 []
```

非法 `action` 返回 400。

### PATCH `/{task_id}/drafts/{draft_id}`
编辑草稿（字段均可选）：`title`、`priority`、`case_type`、`precondition`、`steps`、`expected_result`。编辑后 `review_status=edited`、`was_edited=true`。

### POST `/{task_id}/judge`
手动（重新）运行 AI Judge 评分，刷新草稿评分与质检报告汇总。

### GET `/{task_id}/export?format=xlsx|md&smoke_only=false`
导出候选用例文件流；无可导出用例返回 400。

## 5. 用例库 Testcases

### GET /testcases?project_id=1
全局用例列表，可按项目过滤，响应含 `project_name`。

前缀：`/projects/{project_id}/testcases`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `` | 项目用例列表 |
| GET | `/{case_id}` | 用例详情 |
| PATCH | `/{case_id}` | 编辑用例（`title`/`priority`/`case_type`/`precondition`/`steps`/`expected_result`/`module`/`feature`） |
| DELETE | `/{case_id}` | 删除用例，204 |
| PATCH | `/catalog/rename` | 目录重命名 |

目录重命名请求体：

```json
{ "type": "module", "old_module": "登录", "new_name": "用户登录" }
{ "type": "feature", "old_module": "登录", "old_feature": "密码登录", "new_name": "账密登录" }
```

响应：`{ "updated_items": 5 }`

## 6. 知识库 Knowledge

前缀：`/projects/{project_id}/knowledge`

### POST `` — 201

```json
{ "title": "订单业务规则", "content": "# 订单模块\n## 退款规则\n...", "source_type": "doc" }
```

`source_type`：doc（业务文档）/ case（历史用例）/ defect（缺陷记录）。
入库流程同步完成分块与向量化；内容过短（不足最小分块长度）返回 400。

响应：`id`、`title`、`source_type`、`status`（ready/processing/failed）、`chunk_count`、`error_message`。

### POST `/upload` — 201
文件上传（multipart）：`file`（.md/.docx）、`title`（可选）、`source_type`（可选，默认 doc）。

### GET ``
知识文档列表。

### GET `/{doc_id}/chunks`
分块列表：`content`、`heading`（标题路径，如 `订单模块 > 退款规则`）。

### POST `/search`

```json
// 请求
{ "query": "退款手续费怎么算", "top_k": 5 }
// 响应
[ { "content": "...", "title": "订单业务规则", "heading": "订单模块 > 退款规则", "source_type": "doc", "score": 0.83 } ]
```

相似度低于阈值（0.35）的结果不返回。

### DELETE `/{doc_id}` — 204
删除文档并清理向量。

## 7. AI 评测 Evaluations

前缀：`/evaluations`（全局，数据存放于隐藏评测项目）

### 样本管理

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/samples` | 样本列表 |
| POST | `/samples` | 创建样本（`name`、`prd_content`、`checkpoints[]` 标准测试点），201 |
| PUT | `/samples/{sample_id}` | 更新样本 |
| DELETE | `/samples/{sample_id}` | 删除样本，204 |

### 评测运行

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/runs` | 发起运行（`sample_ids[]`、`label` 运行标签、`strategy`），201，异步执行 |
| GET | `/runs` | 运行列表（含汇总指标） |
| GET | `/runs/{run_id}` | 运行详情：`status`、`progress`、`stage`、`results[]`（每样本指标：成功率/可用率/召回率/重复率/幻觉数/未覆盖测试点） |
| GET | `/tasks/{task_id}` | 评测任务下钻：完整生成任务（草稿、评分、质检报告） |
| DELETE | `/runs/{run_id}` | 删除运行记录，204 |

## 8. 系统设置 Settings

### GET /settings
返回三套模型配置；API Key 仅返回 `*_api_key_set`（是否已配置）与 `*_api_key_masked`（掩码），不回显明文。

### PATCH /settings
字段均可选，只更新提交的字段：

```json
{
  "llm_api_key": "sk-xxx", "llm_base_url": "https://api.deepseek.com/v1",
  "llm_model": "deepseek-v4-flash", "llm_mock_mode": false,
  "eval_llm_api_key": "", "eval_llm_base_url": "", "eval_llm_model": "",
  "embedding_api_key": "", "embedding_base_url": "", "embedding_model": ""
}
```

评测模型留空时回退使用生成模型配置；Embedding 未配置时知识库在 Mock 模式下走伪向量。
