# 评测样本 2：评审入库模块

> 使用方式：在「AI 评测 → 新建样本」中，标题填「评审入库」，正文粘贴下方 PRD 原文，
> 标准测试点按下表逐条录入（text 为测试点描述，keywords 为召回匹配关键词）。
> 该样本取自本平台自身的评审入库模块，生成结果可直接与平台实际行为对照。

## PRD 原文

```
# 评审入库模块 PRD
## 1. 模块概述

AI 生成的候选用例（草稿）需经人工评审后方可进入用例库。本模块提供采纳、驳回、编辑三种评审操作，并统计评审信号（采纳率、编辑率、驳回率）用于衡量 AI 生成质量。

## 2. 功能需求

### 2.1 草稿评审列表

功能描述：生成完成后展示候选用例列表，供逐条或批量评审。

验收标准：
- 列表展示每条草稿的标题、用例类型（功能/边界/异常）、优先级、冒烟标记、质检状态与 AI 评分
- 支持展开查看用例详情：前置条件、操作步骤、预期结果
- 支持按「全部 / 仅冒烟」筛选草稿
- 已采纳与已驳回的草稿复选框禁用，不可重复评审
- 列表分页展示时，「一键全选」可跨页选中全部待评审草稿

### 2.2 采纳入库

功能描述：将选中的草稿转为正式用例存入用例库。

验收标准：
- 采纳成功后草稿状态变为「已采纳」，用例库新增对应用例，来源标记为 AI 生成
- 采纳的用例保留模块、功能点归属，在用例库按目录组织
- 未选择任何待评审草稿时点击采纳，提示「请选择未采纳的用例」

### 2.3 驳回

功能描述：驳回不合格的草稿并记录原因，用于 badcase 归因。

验收标准：
- 驳回必须选择原因（如：重复场景、与需求不符、不可执行、其他）
- 选择「其他」时可填写补充说明，不超过 100 字
- 驳回后草稿状态变为「已驳回」，不可再采纳，原因入库
- 驳回操作需二次确认，确认框展示将驳回的用例数量

### 2.4 编辑草稿

功能描述：采纳前允许修改草稿内容。

验收标准：
- 可编辑标题、优先级、用例类型、前置条件、步骤、预期结果
- 编辑后草稿标记为「已编辑」，该信号计入「编辑后采纳率」统计
- 编辑不改变待评审状态，仍需采纳或驳回

### 2.5 完成评审与统计

功能描述：评审结束后进入完成页，展示本次生成的评审统计。

验收标准：
- 全部草稿处理完毕后自动进入完成页；也可点「完成评审」跳过剩余草稿
- 完成页展示：总生成数、已采纳数、已驳回数、采纳率
- 采纳率 = 已采纳 / 总数，驳回率 = 已驳回 / 总数，统计随评审操作实时更新
- 完成页提供后续动作入口：查看测试用例、导出用例、查看生成记录、再生成一批

## 3. 非功能要求

- 单次批量采纳 100 条以内在 3 秒内完成
- 评审操作不可越权跨项目：只能评审本项目生成任务下的草稿
```
