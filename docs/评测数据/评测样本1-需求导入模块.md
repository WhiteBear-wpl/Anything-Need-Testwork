# 评测样本 1：需求导入与功能点确认模块

> 使用方式：在「AI 评测 → 新建样本」中，标题填「需求导入与功能点确认」，正文粘贴下方 PRD 原文，
> 标准测试点按下表逐条录入（text 为测试点描述，keywords 为召回匹配关键词）。
> 该样本取自本平台自身的需求导入模块，生成结果可直接与平台实际行为对照。

## PRD 原文

```
# 需求导入与功能点确认模块 PRD

## 1. 模块概述

本模块是 AI 生成用例流程的第一步：用户导入需求文档，系统调用 LLM 解析为结构化功能点清单（FeatureList），用户确认后进入用例生成。

## 2. 功能需求

### 2.1 需求导入

功能描述：支持三种方式导入需求——粘贴文本、上传文件、导入功能清单。

验收标准：
- 粘贴文本方式：标题与内容均为必填，为空时不可提交并提示对应字段
- 上传文件仅支持 .docx、.md、.markdown 三种格式，单文件不超过 10MB
- 上传 .doc 旧格式时拒绝，并提示「另存为 .docx 后上传」
- 上传其他非法格式（如 .exe、.pdf）时拒绝并提示支持的格式
- 上传文件不填标题时，默认使用文件名（去扩展名）作为文档标题
- 导入功能清单支持 .xlsx 与 .md，导入成功后直接生成结构化功能点，无需再次解析

### 2.2 功能点解析

功能描述：导入后调用 LLM 将需求原文解析为功能点列表。

验收标准：
- 解析产出的每个功能点包含：模块、功能点名称、描述、验收标准、约束边界、优先级
- 解析成功后文档状态由「已上传」变为「已结构化」，功能点初始为未确认状态
- 解析失败时给出明确原因（如模型 API Key 无效、返回格式非法），文档状态不变可重试

### 2.3 功能点确认与编辑

功能描述：用户核对功能点，可增删改后确认。

验收标准：
- 支持行内编辑功能点全部字段；功能点名称必填，1~200 字符
- 支持手工新增功能点与删除功能点，删除需二次确认
- 支持全量确认与勾选部分功能点确认，仅被勾选的功能点计入生成范围
- 全部确认后文档状态变为「已确认」；已确认文档的功能点被修改后，状态回退为「已结构化」，需重新确认
- 未确认的文档禁止发起用例生成，接口返回明确提示

### 2.4 测试范围卡片

功能描述：维护本次测试的「不测范围」与「风险/待澄清」，影响后续生成。

验收标准：
- 不测范围与风险支持手工填写（每行一条）并保存，刷新后保留
- 支持 AI 一键生成范围建议，生成后可再编辑
- 生成用例时读取该卡片：不测范围内的场景跳过，风险项优先补测

## 3. 非功能要求

- 功能点解析在 30 秒内完成（10 个功能点以内的文档）
- Mock 模式下解析返回内置示例功能点，保证无 API Key 也能走通流程
```

## 标准测试点（checkpoints）

粘贴文本时标题与内容必填校验 | 标题, 内容, 必填
仅允许 .docx/.md/.markdown 格式上传 | docx, md, 格式
文件大小 10MB 上限校验 | 10MB, 上限
.doc 旧格式拒绝并提示转存 .docx | doc, 另存, docx
非法格式（exe/pdf）上传被拒绝 | 非法, 拒绝
不填标题时默认取文件名 | 标题, 文件名, 默认
功能清单 xlsx/md 导入直接生成功能点 | 功能清单, 导入
解析产出功能点字段完整性 | 模块, 优先级, 验收标准
解析失败给出明确原因且可重试 | 解析失败, 原因, 重试
功能点名称 1~200 字符边界校验 | 200, 字符, 边界
新增与删除功能点（删除需确认） | 新增, 删除, 确认
部分勾选确认仅勾选项计入生成 | 勾选, 部分, 确认

未确认文档禁止发起生成 | 未确认, 禁止, 生成
测试范围保存与生成时生效（跳过不测/补测风险） | 不测范围, 风险, 跳过
