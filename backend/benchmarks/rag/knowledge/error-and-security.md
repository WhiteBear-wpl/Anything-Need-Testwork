# 错误处理与项目安全

AITC 的业务接口需要把调用失败转换为可读中文提示，并且任何项目资源访问都必须经过项目成员权限校验，防止跨项目读取或评审数据。

## 文件格式与输入边界

需求和知识文档只接受 `.docx`、`.md`、`.markdown`。旧版 `.doc` 必须提示用户另存为 `.docx`，其他格式如 `.pdf` 或 `.exe` 直接拒绝；单文件不得大于 10MB。

## 模型调用失败提示

Embedding 或生成模型的 401、403 表示 API Key 无效或已过期，429 表示限流，404 表示接口地址或模型名有误。请求或网络异常必须给出连接服务失败提示，而不是暴露密钥。

## 项目隔离与越权保护

知识检索、草稿评审、用例读取和 Agent 查询均在路由构建时绑定项目 ID。用户不能借助其他项目的文档、草稿或向量数据得到结果。
