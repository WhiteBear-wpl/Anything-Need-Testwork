# 知识库模块 PRD

## 1. 模块概述

本模块为每个项目提供独立的测试知识库，用于沉淀业务规则、接口文档与历史缺陷记录。知识入库后自动分块并向量化，在 AI 生成用例前可检索相关知识注入提示词（RAG），补充 PRD 缺失的业务背景并减少幻觉。

## 2. 功能需求

### 2.1 知识文档上传

**功能描述：** 用户在知识库页上传文档或粘贴文本，系统自动分块、向量化并入库。

**验收标准：**
- 支持上传 .md 与 .docx 文件，上传成功后列表新增记录，状态为「已入库」
- 支持选择来源类型：业务文档 / 历史用例 / 缺陷记录
- 上传非支持格式（如 .exe）时拒绝并提示支持的格式
- 文档内容过短（少于最小分块长度）时入库失败并给出明确提示
- 入库失败的文档状态显示「失败」，并可查看失败原因

**约束条件：**
- 单个文件不超过 10MB
- 未填标题时默认使用文件名（去扩展名）

### 2.2 文档分块

**功能描述：** 入库时按 Markdown 标题层级切分为知识块，供后续检索。

**验收标准：**
- 按标题层级分块，每块保留「一级 > 二级」标题路径
- 超长内容按句子边界二次切分，单块不超过 500 字符
- 入库后可在「查看分块」中预览全部分块内容与标题路径
- 列表展示每篇文档的分块数量

### 2.3 知识检索

**功能描述：** 提供检索测试入口，验证知识库召回效果；生成用例时自动按功能点检索。

**验收标准：**
- 输入问题点击「检索」，返回按相似度降序的命中列表，展示来源文档、标题路径与相似度分数
- 相似度低于阈值的结果不返回
- 知识库为空时检索返回空结果，页面不报错
- 开启「知识库检索」开关生成用例时，按功能点自动检索并注入提示词，生成结果页展示引用的知识条目

### 2.4 文档删除

**功能描述：** 删除不再需要的知识文档。

**验收标准：**
- 删除需二次确认，确认后列表移除该文档
- 删除文档同时清理对应向量，再次检索不会命中已删除内容
- 删除项目时级联清理该项目全部知识文档与向量

## 3. 界面要求

- 知识库为全局入口，页面顶部提供项目切换器，明确展示当前管理的项目
- 文档列表展示标题、来源类型、状态、分块数、入库时间与操作
- 上传区支持点击与拖拽两种方式

## 4. 非功能要求

- 单篇文档入库（含向量化）不超过 30 秒
- 未配置 Embedding 模型时，Mock 模式下使用伪向量保证功能可用
- 知识内容仅存储于本地（SQLite + 本地向量库），不上传第三方
